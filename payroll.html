Employee Status Salary Due (editable) Paid (Zoho) Actual Salary (editable) Adv. Deducted (editable) Advance (month) Advance Outstanding
Salary Due = full salary for the month (you set it). Actual Salary = what was really paid (type it, or leave blank to use the Zoho figure). Adv. Deducted auto-fills as Due − Actual; edit it if the deduction differs — the rest shows as "unpaid". Period = "Monthly cycle" runs from the "cycle starts on day" you set (e.g. 14 Mar – 13 Apr), not the calendar month. Switch Period to "Custom dates" to set any From / To range instead — figures you type are saved against that exact range. Advance Outstanding = advance taken (from Zoho) minus all deductions made in this tool across months. Nothing negative is written to Zoho Books — deductions are managed entirely inside this tool and saved on this computer. Click an employee's Active / Inactive badge to change it. Status is set by hand and saved on this computer, not in Zoho Books.
